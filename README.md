Stone Paper Scissors Game is a classic hand game where two players choose stone, paper, or scissor to compete against each other.
This repository contains a simple implementation of the Stone Paper Scissors game. You play against the computer, which picks a random choice each round.
Game Rules
• Stone beats Scissor (stone crushes scissor).
• Scissor beats Paper (scissor cuts paper).
• Paper beats Stone (paper covers stone).
• Same choices result in a Tie/Draw
